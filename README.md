# 📚 Book Finder

## Overview
Book Finder is a React application that allows users to search for books by title using the **Open Library API**.  
It displays book details including cover image, title, author(s), and first published year.  

This project demonstrates API fetching, state management in React, and a clean user interface.


## Features
- Search for books by title  
- Display book cover, title, author(s), and first published year  
- Handles empty search:
  - Shows "Please enter a book title to search!"  
- Handles invalid search:
  - Shows "No books found!"  
- Responsive grid layout for desktop and mobile  
- Hover effects on book cards  
- Loading indicator while fetching data
